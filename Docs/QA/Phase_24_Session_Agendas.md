# Phase 24 — Session Agendas

Default duration: 60–90 minutes. Facilitator opens **Stakeholder Validation → Prepare round** before start.

---

## Round 1 — Product shell, portals and navigation

| Item | Detail |
|---|---|
| Objective | Confirm portal architecture, roles, terminology, org/period context |
| Roles | Focal, MoIP Reviewer, Secretary, Minister, PMO |
| Decisions | Portal set OK? Terminology OK? Context clear? |
| Agenda | 10m context · 40m walk portals · 15m decisions · 10m open questions |
| Outputs | Attendance, decisions, open questions |

| Item | Detail |
